# StepFlow — Интерактивные инструкции и анализ узких мест

Веб-приложение для создания и интерактивного выполнения пошаговых сценариев, инструкций и регламентов. Проект разработан для трека «Веб-разработка» Всероссийского хакатона по информационным технологиям «TASKILLS 2026».

---

## Назначение проекта

Классические текстовые регламенты и видеоинструкции имеют два ключевых недостатка:
1. **Со стороны пользователя**: при выполнении многоэтапных задач (настройка сервера, сборка ПК, оформление документов) легко упустить промежуточный пункт, что приводит к ошибкам или необходимости начинать заново.
2. **Со стороны автора**: составитель инструкции не получает обратной связи о том, на каких конкретно шагах читатели сталкиваются с трудностями, где тратят больше всего времени и на каком этапе бросают процесс.

StepFlow объединяет интерактивный режим выполнения с встроенной системой сбора телеметрии прохождения. Пользователь последовательно закрывает чек-листы каждого шага, а автор видит объективную воронку отсева (Drop-off Funnel) и среднее время прохождения каждого этапа.

## Реализованные возможности

### Прохождение сценариев (Player)
- Пошаговая навигация с фиксацией выполненных пунктов чек-листа в каждом этапе.
- Сохранение прогресса прохождения в локальном хранилище браузера (LocalStorage).
- Режим фокуса (Zen Mode) по клавише `F` — скрывает лишние панели интерфейса для концентрации на задаче.
- Навигация с клавиатуры (стрелки влево/вправо для перехода между этапами, слэш `/` для быстрого поиска).
- Оценка понятности каждого отдельного шага («Понятно» / «Есть вопросы») и блок вопросов к автору.

### Каталог сценариев
- Разделение по тематическим категориям: Hardware & DIY, ВУЗ & Документы, IT & DevOps, Регламенты & Быт.
- Фильтрация по уровням сложности (базовый, средний, сложный).
- Полнотекстовый поиск по названиям, описаниям и тегам.
- Отображение текущего прогресса выполнения прямо в карточках каталога.

### Конструктор регламентов (Studio)
- Добавление и удаление этапов с возможностью изменения их порядка.
- Настройка вложенных чек-листов, расчетного времени, предупреждений и рекомендаций.
- Панель контроля качества структуры (процент покрытия чек-листами, общее время, наличие пояснений).
- Стартовые шаблоны типовых сценариев (сборка оборудования, регламент подачи документов, DevOps runbook).

### Аналитика узких мест (Analytics)
- Наглядная воронка удержания по этапам (Drop-off Funnel) в процентах.
- Сопоставление фактического среднего времени прохождения с плановым нормативом.
- Автоматическая фиксация проблемных шагов с повышенным процентом отсева (>10%) или задержками по времени.

### Форки и экспорт
- Механизм создания ответвлений (форков) с сохранением авторства исходного сценария и фиксацией номера версии.
- Готовая разметка для сохранения в PDF через стандартный диалог печати браузера (`Ctrl+P`).
- Экспорт инструкции в формат Markdown (`.md`).
- Генерация HTML-кода iframe для встраивания плеера во внешние базы знаний или порталы.

### Интерфейс
- Переключение ролей «Исполнитель» / «Автор» для разграничения режимов чтения и редактирования.
- Светлая и тёмная темы оформления с сохранением пользовательского выбора.

## Установка и запуск

Для работы требуется Node.js версии 18 или выше.

### 1. Клонирование репозитория
```bash
git clone https://github.com/pivnoyanchous/taskills-starting-2026.git
cd taskills-starting-2026
```

### 2. Установка зависимостей
```bash
npm install
```

### 3. Запуск в режиме разработки
```bash
npm run dev
```
После запуска интерфейс будет доступен по адресу `http://localhost:5173`.

### 4. Сборка production-версии
```bash
npm run build
```
Готовые статические файлы будут собраны в директорию `dist/`.

## Демонстрационные сценарии в комплекте

В приложение включены 4 демонстрационных регламента, покрывающих различные предметные области:
1. **Сборка современного ПК с нуля**: 8 шагов с детальными чек-листами установки процессора, памяти и подключением передней панели корпуса.
2. **Установка и настройка Docker & Docker Compose на Linux**: 5 шагов по настройке официального репозитория, non-root доступа и параметров ротации логов в `daemon.json`.
3. **Оформление академической справки в деканате ВУЗа**: 4 шага по подготовке бланка, проверке задолженностей и подаче заявления.
4. **Оформление отчета по лабораторной работе по ГОСТ 7.32-2017**: 4 шага с правилами разметки полей, шрифтов, формул и списков литературы.
